# ISO/IEC 42001 → AGL Adapter

Maps ISO/IEC 42001 AI management-system references into AGL governance evidence.

The adapter:
- preserves the ISO/IEC 42001 version;
- maps a requirement/control reference to an AGL policy node;
- records implementation state as evidence;
- preserves the external standard reference.

AGL does not reproduce licensed ISO text and does not claim certification or conformity from the presence of a mapping. ISO/IEC 42001:2023 specifies requirements for establishing, implementing, maintaining and continually improving an AI management system.

Source: ISO/IEC 42001:2023.

# NIST AI RMF → AGL Adapter

Maps NIST AI Risk Management Framework references into AGL governance evidence.

Supported AI RMF functions:
- Govern
- Map
- Measure
- Manage

The adapter preserves the NIST control/subcategory reference and records implementation state as evidence. It does not reproduce NIST guidance or determine legal compliance.

NIST describes AI RMF 1.0 as a voluntary framework organized around Govern, Map, Measure and Manage. The framework is currently being revised, so AGL records the framework/version reference explicitly.

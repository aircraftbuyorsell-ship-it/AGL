# Changelog

All notable changes to this plugin are recorded here. The plugin follows [Semantic Versioning](https://semver.org/); `version` in `.claude-plugin/plugin.json` is raised with every release.

## 1.0.0 — 2026-10-15

First public release.

- `aircraft-prebuy` skill: intake, listing triage, logbook and records review, registry and title checks (FAA and EASA), pre-buy inspection planning, red flags and fraud signals, seller questions, and a structured pre-buy report.
- Reference documents for each step under `skills/aircraft-prebuy/references/`.
